TOUR DA CAPE — COORDINATED DESIGN AND WATERFRONT IMAGE FIX

This is a complete replacement website folder, not a single-file patch. It includes all seven HTML pages and the shared stylesheet/assets.

What changed:
- Replaced the Accommodation hero’s Bo-Kaap photo with the Cape Town hero image so the photo matches its description.
- The V&A Waterfront area card now uses a separate filename, va-waterfront-area.webp, copied from the harbour photograph supplied for this site. This avoids an old cached cape-town-city.jpg being shown in that card.
- Softened the pure-white page canvas to a warm off-white and used a slightly deeper warm tone for alternating sections; white cards remain to keep text readable and images visually distinct.
- Added shared responsive rules for page heroes, area cards, content widths and spacing at desktop/tablet/mobile sizes.
- Kept the existing page content and homepage structure; the homepage was not redesigned.

HOW TO APPLY
1. Download and extract the ZIP.
2. Replace the corresponding website files with the files in this folder (upload the full folder contents to the repository root, preserving the existing CNAME/robots/sitemap and verification files if they are not included here).
3. Commit the changes.
4. After deployment, hard-refresh with Ctrl+F5. If GitHub Pages is still serving a previous deployment, wait for the deployment to finish before checking.

IMAGE NOTE
The supplied harbour photograph is a broad aerial view of Cape Town harbour; it is not a close-up of the Clock Tower or the V&A shopping precinct. The new filename ensures the Accommodation card loads the supplied file rather than a stale image with the old name.
