TOUR DA CAPE WEBSITE UPDATE — OCTOBER 2026

This update refines the existing multi-page website based on your feedback. It does not claim to publish changes to GitHub automatically.

KEY CHANGES
- Compact, consistent footer styling across all included pages.
- Less dark green and less oversized enquiry banners.
- WhatsApp contact actions are retained on Home and Contact only. Other pages link visitors to Contact.
- Contact page has a more restrained layout, clearer contact options and a compact enquiry form.
- Email address is bookings@tourdacape.co.za.
- The original Tour Da Cape logo file is retained.
- Existing tour information includes Aquila half-day/full-day enquiries, Atlantis Dunes quad biking/transport, and Hermanus whale-watching/transport.

HOW TO APPLY
1. Extract this ZIP on your computer.
2. In the existing TourDaCape GitHub repository, upload and replace the matching HTML and style.css files from this package.
3. Keep existing files not included in this ZIP (including script.js, site-config.js, CNAME, robots.txt and sitemap.xml). Do not delete the repository contents.
4. Wait for GitHub Pages to publish, then check each page on desktop and mobile.

FILES INCLUDED
index.html, tours.html, transfers.html, accommodation.html, travel-planning.html, about.html, contact.html, style.css, READ-ME-FIRST.txt, and the image assets used by these pages.
